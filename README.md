# Hands-on Labs - Microsoft Agent Framework

Welcome to the source repository of the Microsoft Agent Framework Hands-on Labs by [Marcel de Vries](https://github.com/vriesmarcel), [Roy Cornelissen](https://github.com/roycornelissen) and [René van Osnabrugge](https://github.com/renevanosnabrugge).

The lab description can be found in the [Wiki](https://github.com/XpiritCommunityEvents/HOLAgentFramework/wiki) section of the main repo. Please follow the instructions there.

## Prerequisites

**GitHub Codespaces** provides the required .NET 10 SDK through the dev container.
For local development, install the SDK selected by `global.json` (10.0.404 or a
newer .NET 10 feature band). Follow the Wiki for the remaining prerequisites,
model configuration, and step-by-step lab instructions.
