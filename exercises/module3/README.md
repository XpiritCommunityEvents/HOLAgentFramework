# Module 3: Amplify Performance with Retrieval Augmented Generation

All exercises and labs are described in detail on the [Wiki page](https://github.com/XpiritCommunityEvents/HOLAgentFramework/wiki) that comes with this workshop.

Use `GetResponsesClient().AsIChatClient(model)` for the conversational agent in
both the starter and completed RAG exercises. Keep the Azure resource-root
endpoint: the code appends `openai/v1/`. Embedding clients and their deployment
configuration are unchanged. Structured output and context providers continue
to use Agent Framework APIs. See the
[API conventions](../../README.md#model-api-conventions).
