# Prerequisites for the HandsOn Labs - Agent Framework

To prepare for the upcoming full-day workshop, please ensure your development environment is ready. You will be working in a cloud-based GitHub Codespace or, if preferred, from your own local Visual Studio Code environment.

## 1. GitHub Account

- You must have an active GitHub account before the workshop.

- You can use your personal GitHub account — there is no need to create a separate one.

- Verify that you can log in successfully at https://github.com.

During the workshop, you will be added as a participant to a dedicated GitHub organization that will be provided by us.

You’ll receive an invitation to join this organization during the day

This organization will host the workshop repositories and automatically provision your personal Codespace environment.

## 2. Codespace Environment

- A personal Codespace will be created for you within the provided GitHub organization.

- The Codespace is a cloud-based development environment with all required tools and extensions preinstalled.

- You can access it directly in your browser, no local installation required.

- A modern browser (Chrome, Edge, or Safari) is recommended.

## 3. (Optional) Try Creating a Codespace in Your Own Public Repository

To confirm your GitHub account can use Codespaces, you can try creating one yourself:

1. Go to https://github.com/new and create a new public repository (any name is fine).

2. Once created, open your repository and click the “<> Code” button near the top.

3. Select the “Codespaces” tab.

4. Click “Create codespace on main” to launch your Codespace.

5. Wait for the environment to start — this may take a few minutes the first time.

When the environment opens in your browser (a web-based version of Visual Studio Code), you’ve confirmed that Codespaces works for your account.

For more details, see GitHub’s official guide:
👉 Creating a Codespace in a Repository

## 4. Option: Run Locally with Visual Studio Code

If you prefer to use your local Visual Studio Code setup instead of the browser-based Codespace:

- Install Visual Studio Code from https://code.visualstudio.com/.

- Ensure you have permission to install and manage VS Code extensions on your machine.

- During the workshop, you can connect your local VS Code to the provided remote Codespace (or dev container).

## 5. General Technical Requirements

- A GitHub account with Codespaces access.

- Ability to receive and accept an invitation to the provided GitHub organization.

- Browser pop-ups enabled to accept repository or Codespace invitations.

No additional software or configurations are needed before the session — setup will be completed during the workshop.
